# My reading

A personal app to keep track of the books I read.
It runs in the browser and can be installed on a phone as an app (PWA).

## Features
- Library with statuses: Reading, Finished and Abandoned
- Reading sessions with start and end page
- Monthly reading calendar and yearly pages chart
- Notes, rating, favourite quotes and a cover for each book
- Photos of pages with text recognition (OCR) and translation
- Add books by ISBN (barcode scanner)
- File backup, photos included
- Six languages: Spanish, English, Italian, German, French and Japanese

## Data
Everything is stored on the phone itself. No accounts, no servers.
Make backups from the Statistics screen.

## Files
- index.html: the whole application
- sw.js: offline support
- manifest.webmanifest: installation on the phone
- icon-192.png, icon-512.png: icons

## Updating
Upload the new index.html (Add file → Upload files) and confirm with Commit changes.
